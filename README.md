# Expeditionary Hardcore

Respawn in a random location on each death, with randomized quirks and starting items.

![banner](page/banner-exp-hardcore.jpg)

_Credits to the people behind the Obsidian Expedition [animated opening](https://www.youtube.com/watch?v=Wgpp8rElCbU) for the banner_

With this mod, a new game mode, Expedition, is added. With it, every time you
die you respawn in a random location. Additionally, every life uses a new
character, that has a random skin, starting item loadout, and quirks.
Quirks, in particular, are small effects permanently affecting a character,
such as attribute changes or rarely hearing sounds.

Every character has their Expeditioner's Logbook, where you can set the character's
name, and after write as in a normal book. If you stumble upon a previous death
position, you may find a lost logbook...

Many things from enabling specific features to specifics on how respawn location
is picked can be configured (see below).

See the [Modrinth](todo) or [Curseforge](todo) page, and the [WIKI](https://github.com/filloax/expeditionary-hardcore/wiki)
for more information. For bug reports check the [Issues](https://github.com/filloax/expeditionary-hardcore/issues).

Originally made for a streaming series, [The Obsidian Expedition](todo). Check it out! Especially the
amazing [website](https://hardcore.projectegobalego.com/) with all the community fanart, animated
opening, and contribution.

## Config

See [wiki](https://github.com/filloax/expeditionary-hardcore/wiki/Config) for complete info.

Most individual features other than respawning can be disabled, such as character Quirks,
starting loadouts, and skin/model replacement.

The respawn behavior is configurable. Other than radius, you can pick the origin point for random
spawn from
- last respawn
- last death
- world origin
- nearby strongholds (specifically, random stronghold among 3 closest ones from death pos)

## Multiplayer

The mod supports multiplayer! If the config for it is enabled, there also is a team system
to allow players in the same team to respawn close to one player designated as the main one.
Main player will respawn as normal per the gamemode, other players within a close range.

Teams can be made via `/exphardcore team invite`. FTB Teams support is planned.

## Cydonia mode?

If you check the Github releases, you may notice an additional version labeled "cydonia". That
is the version the streamed run uses, which has some tweaks and mainly features to connect to the
APIbalego website and send data in realtime. **This data sending is not in the normal version!**
This version is not recommended for players.
